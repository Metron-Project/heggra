# Example project

[`example/`](https://github.com/Metron-Project/heggra/tree/main/example) is a small Django project,
styled with Bulma, that uses the widget on a required image field and an optional file field. Its
[README](https://github.com/Metron-Project/heggra/blob/main/example/README.md) explains how to run
it.
